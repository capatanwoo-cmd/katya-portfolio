# Катя Сидорова — портфолио

Графический дизайн, инфографика, упаковка, 3D-визуализация и рекламные креативы.

Статический сайт на HTML, CSS и JavaScript. Для публикации в GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Обновление

- `index.html` — тексты, опыт, образование и контакты.
- `styles.css` — оформление и адаптивные версии.
- `projects.js` — описания, категории и состав галерей проектов.
- `app.js` — фильтры, просмотр проектов и изображений.
- `work-*.webp` — оптимизированные изображения работ.

Для локального просмотра: `python3 -m http.server 8765` в папке сайта, затем открыть http://localhost:8765.

Фотография автора пока не добавлена. На первом экране использованы её работы. Метрики эффективности и отзывы не заявляются.

Изображения и дизайн-проекты представлены в составе авторского портфолио. Логотипы и товарные знаки принадлежат их правообладателям. Лицензия на повторное использование работ не предоставляется.
